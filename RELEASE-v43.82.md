# SWÉ Tournament V43.82

- Les boutons **Je participe** et **Je ne participe pas** sont placés avant le profil joueur sur le lien d’invitation.
- Le co-gestionnaire est redirigé vers le bon espace SWÉ et peut afficher ou masquer ses consignes.
- L’administrateur peut rédiger une consigne privée différente pour chaque co-gestionnaire.
- Les équipes constituées peuvent être renommées par l’administrateur.
- Après une modification manuelle des compositions, les joueurs réellement en trop sont recalculés comme remplaçants.
- Les remplaçants restent proposés pour un match tant qu’ils ne jouent pas dans un autre match en cours.
