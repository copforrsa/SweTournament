# SWÉ Tournament 5/5 — V42.25

- Création manuelle d’une équipe par l’administrateur via une opération sécurisée.
- Déplacement possible d’un joueur déjà affecté vers une équipe manuelle.
- Une équipe manuelle incomplète est conservée et ses places libres sont complétées lors de la génération aléatoire.
- À l’ajout d’un invité, l’administrateur peut sélectionner son membre de rattachement (« Guest de… »).
- Les ajouts restent disponibles après la fermeture des inscriptions publiques.
