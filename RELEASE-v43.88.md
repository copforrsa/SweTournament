# SWÉ Tournament V43.88

- Le Super Admin voit chaque co-organisateur avec son email, son espace, son organisateur et son statut de paiement réel : payé par l’organisateur, payé par lui-même ou en attente.
- Le statut individuel s’appuie sur les abonnements Stripe et les invitations existantes.
- L’organisateur peut rattacher un co-organisateur à un membre depuis la liste des accès, sans modifier ses autorisations.
- Le rattachement est verrouillé après validation afin de préserver les identités ; les notes et statistiques existantes sont conservées.
- Migration additive : aucune équipe, inscription, présence, composition, vote, match ou score existant n’est modifié.
