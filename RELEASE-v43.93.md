# SWÉ Tournament V43.93

- Le suivi des évaluations utilise désormais le même total pour tous : tous les membres du groupe sont comptabilisés.
- Le dashboard indique le nombre de joueurs jamais notés et permet d’ouvrir la liste des noms manquants, globalement et par évaluateur.
- L’espace Joueurs affiche clairement les statuts actif/inactif et leur origine. Après quatre tournois consécutifs manqués, le joueur passe automatiquement inactif lors de la clôture du tournoi ; l’administrateur peut toujours le réactiver.
- La page Équipes reçoit une feuille de présence réservée à l’administrateur : à l’heure, retard avec durée, absent ou désistement de dernière minute.
- Les retards et désistements sont visibles automatiquement sur la page publique d’inscription. Un désistement recalcule immédiatement les remplaçants.
- Migration additive : aucune donnée du tournoi en cours n’est réinitialisée.
